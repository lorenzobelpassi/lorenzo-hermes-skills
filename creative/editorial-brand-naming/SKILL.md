# Editorial brand naming

Use this skill when the user is naming a newsletter, column, media brand, recurring dispatch, content product, or editorial series.

## Core approach

1. Identify the tension the name must hold.
   - Audience: who should feel addressed?
   - World: what industry/subculture should it signal?
   - Edge level: polished, insider, gritty, luxury, irreverent, trade-floor, etc.
   - Scope: narrow enough to own, broad enough to grow.

2. Generate in families, not isolated names.
   - Literal/direct names
   - Insider slang names
   - Place/infrastructure names
   - Object/tool names
   - Verb/action names
   - Contrarian or gossip-sheet names

3. Package the strongest names.
   - Name
   - One-line rationale
   - Tagline
   - Section architecture
   - Companion/offspring names for recurring editions

4. Iterate by moving between poles.
   - If the user says "more edgy," increase subculture specificity, pressure, slang, and opinion.
   - If the user says "between," preserve the stronger DNA while softening the most extreme word.
   - If the user asks for a concept in the title, incorporate it directly or through adjacent trade language.

5. End with a clear recommendation.
   - Rank options.
   - Say which one you would lock and why.
   - Keep the explanation short enough that the user can react quickly.

## Style rules

- Avoid generic food-media names unless the user wants broad consumer appeal.
- Prefer concrete nouns from the user's world: tools, rooms, documents, rituals, stations, slang.
- Use subtitles/taglines to clarify; let the name carry attitude.
- Show how the brand can become a system: main title, weekday editions, sections, occasional columns.
- Do not over-explain every option. Give the user handles they can react to.

## Verification checklist

Before finalizing:
- Does the name feel ownable, not generic?
- Does it imply the correct audience and world?
- Can it support recurring sections?
- Does the tagline make the promise clear?
- Did you provide a decisive recommendation, not just a list?
